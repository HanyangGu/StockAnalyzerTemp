StockAnalyzer 开发报告
针对于此临时版本

架构代码重构：
原始单文件 app.py 拆分成多个独立模块，按 core/ analyzers/ scoring/ engine/ 四个文件夹组织
新增 orchestrator.py 作为主协调器，composite.py 专门负责多维度权重合并
UI 评分卡从 5 个小卡改为 3 个主维度大卡（技术面 / 基本面 / 情绪面），细节放入折叠面板

新功能情绪面 — 新闻情绪分析：
双来源抓取：yfinance 综合新闻 + 专项搜索，自动去重，最多送 12 篇给 GPT 分析
GPT 对每篇文章从 7 个维度打分：情绪方向、情绪强度、影响力、影响范围、可信度、新颖性、市场预期偏差
三档相关性过滤：direct 全权重 / indirect ×0.4 / unrelated ×0，无关新闻不参与计分
时间衰减 + 影响力保底：major 级事件即使是数周前也保持最低 0.5 权重
情绪一致性修正：所有文章方向高度一致时加分，高度分歧时减分（需至少 3 篇相关文章）

新功能情绪面 — 分析师评级分析：
8 个维度综合评分：评级分布、分析师权威度、时间衰减、评级趋势、目标价偏差、目标价离散度、首次覆盖加成、一致性修正
GPT 自动判断机构级别（顶级 / 主流 / 一般），权重分别为 2.0× / 1.2× / 0.7×
6 个月主窗口，不足 5 条自动扩展到 12 个月；不足 3 条返回中性低置信分
新闻 60% + 分析师 40% 加权合并成情绪总分

新功能情绪面 — 内部人交易

新功能复合评分升级：
权重更新：技术面 50% + 基本面 30% + 情绪面 20%
每个维度独立 threshold：技术 >50 / 基本面 >55 / 情绪 >60，避免情绪面低置信分误触发强决策
决策象限从 4 个扩展到 6 个，新增 Cautious Buy（谨慎买入）和 Value Watch（价值观望）
